- This project is now a real Next.js app.
- Vercel Framework Preset should be Next.js.
- package.json contains next, react, and react-dom.
- pnpm-lock.yaml should be committed.
- package-lock.json should not be committed.

If Vercel runs npm install:
1. Delete package-lock.json if it appears again.
2. Commit pnpm-lock.yaml.
3. Clear Vercel build cache and redeploy.
4. Leave Install Command empty/default unless you have a specific reason.

If Vercel says "No Next.js version detected":
1. Confirm Root Directory points to the folder containing package.json.
2. Confirm Framework Preset is Next.js.
3. Confirm package.json includes next in dependencies.
4. Clear Vercel build cache and redeploy.
